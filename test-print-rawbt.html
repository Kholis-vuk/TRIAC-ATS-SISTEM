Test Print RawBT

Buka halaman ini di Chrome Android yang sudah terpasang aplikasi N Printer (atau RawBT) dan sudah tersambung ke printer thermal.

Pengaturan

Struk

Teks bebas

Pratinjau

Pratinjau hanya perkiraan. Ukuran huruf besar dan QR code tampil sebagai penanda.

Cara pakai

  1. Install NPrinter.apk (atau RawBT dari Play Store).
  2. Buka aplikasinya → Pilih Printer Bluetooth → Test Print.
  3. Buka halaman ini di Chrome Android, lalu tekan Cetak Struk.
  4. Kalau muncul pilihan aplikasi, pilih RawBT. Kalau tidak ada respon, ganti metode kirim.
